# M1 基础 CLI 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 打通 `wavecode exec "<prompt>"` 非交互模式与基础交互 REPL，使用 MiniMax（Anthropic Messages 原生格式）完成真实端到端 agent 会话（含工具调用）。

**Architecture:** 按 SPEC §1 协议统摄架构落地 M1 子集：`protocol`（Submission/Event 最小集）→ `core`（session + turn 状态机）→ `app-server`（transport trait + 进程内实现）→ `cli`（clap：exec 子命令 + 默认 REPL）。`llm` 提供 Anthropic 流式客户端，`tools` 提供 5 个内置工具，`config` 提供用户级 TOML 配置。M1 不含审批流（自动放行，工具调用全程可见）、不含 compaction（M4）、ratatui TUI 延后到 M2。

**Tech Stack:** Rust 1.96（edition 2024）、tokio、reqwest（rustls + stream）、serde/serde_json、clap 4、rustyline、async-trait、async-stream、thiserror/anyhow、tracing。

**API 事实（MiniMax，用户提供）:** base_url `https://api.minimaxi.com/anthropic`，模型 `MiniMax-M3`，Anthropic Messages 原生格式 → 请求 `POST {base_url}/v1/messages`，头 `x-api-key` + `anthropic-version: 2023-06-01`。

**凭据安全红线:** API key 只写入 `~/.wavecode/config.toml`（用户级，仓库外）；**绝不**写入仓库内任何文件；`.gitignore` 增加 `.wavecode/` 防项目级配置误提交；测试代码与 fixtures 不含真实 key。

```rust
use serde::{Deserialize, Serialize};

/// 前端 → core 的一次请求；id 由前端生成（uuid），关联后续全部事件
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct Submission {
    pub id: String,
    pub op: Op,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(tag = "type", rename_all = "snake_case")]
#[non_exhaustive]
pub enum Op {
    UserInput { text: String },
    Interrupt,
    Shutdown,
}

/// core → 前端的事件；id 回填对应 Submission.id
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct Event {
    pub id: String,
    pub msg: EventMsg,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(tag = "type", rename_all = "snake_case")]
#[non_exhaustive]
pub enum EventMsg {
    TurnStarted { turn_id: String },
    AgentMessageDelta { text: String },
    AgentMessageComplete { text: String },
    ToolCallBegin { call_id: String, tool: String, input: serde_json::Value },
    ToolCallEnd { call_id: String, ok: bool, output: String },
    TokenCount { used: u64, window: u64 },
    Warning { message: String },
    Error { message: String, recoverable: bool },
    TurnCompleted { stop_reason: StopReason },
}

#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "snake_case")]
pub enum StopReason {
    Completed,
    Interrupted,
    Error,
}
```

### llm crate — 公共类型（`crates/llm/src/lib.rs` 与 `anthropic.rs`）

```rust
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "lowercase")]
pub enum Role { User, Assistant }

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum ContentBlock {
    Text { text: String },
    ToolUse { id: String, name: String, input: serde_json::Value },
    ToolResult { tool_use_id: String, content: String, #[serde(default)] is_error: bool },
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct Message { pub role: Role, pub content: Vec<ContentBlock> }

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct ToolSpec {
    pub name: String,
    pub description: String,
    pub input_schema: serde_json::Value, // JSON Schema object
}

#[derive(Debug, Clone, Default, PartialEq)]
pub struct Usage { pub input_tokens: u64, pub output_tokens: u64 }

/// 流式事件（由 SSE 解析产生）
#[derive(Debug, Clone, PartialEq)]
pub enum StreamEvent {
    TextDelta { text: String },
    ToolUseBegin { id: String, name: String },
    ToolUseInputDelta { partial_json: String },
    BlockEnd,
    MessageComplete { stop_reason: String, usage: Usage },
}

pub struct ChatRequest {
    pub model: String,
    pub system: String,          // M1：单一静态系统提示词（cache 分层 M4 再做）
    pub messages: Vec<Message>,
    pub tools: Vec<ToolSpec>,
    pub max_tokens: u32,
}

#[async_trait::async_trait]
pub trait ChatModel: Send + Sync {
    /// 流式发起一次采样；返回 StreamEvent 流（含错误为 Err 项）
    async fn stream(
        &self,
        req: ChatRequest,
    ) -> wavecode_llm::Result<
        std::pin::Pin<Box<dyn futures::Stream<Item = wavecode_llm::Result<StreamEvent>> + Send>>,
    >;
}
```

`AnthropicClient::new(base_url: String, api_key: String) -> Self`；`impl ChatModel for AnthropicClient`。请求体序列化为 Anthropic Messages API 格式（`ContentBlock` 的 serde 表示即 API 格式，tool_result 用 `{"type":"tool_result",...}`）。SSE 解析为纯函数：

```rust
/// 解析单行 SSE `data:` 负载为 StreamEvent；返回 Ok(None) 表示
/// 该事件无需向上传递（ping/message_start/content_block_stop 由解析器内部处理）
pub fn parse_sse_data(data: &str) -> wavecode_llm::Result<Option<StreamEvent>>;
```

注意：Anthropic SSE 的 `content_block_delta` 需区分 `text_delta` 与 `input_json_delta`；`content_block_start` 中 `content_block.type == "tool_use"` 时取 `id`/`name`；`message_delta` 取 `delta.stop_reason` 与 `usage.output_tokens`；`message_start` 取 `message.usage.input_tokens`（解析器内部累计，最终汇入 `MessageComplete.usage`）——因此解析器实际是有状态的，封装为：

```rust

pub struct SseParser { input_tokens: u64 }
impl SseParser {
    pub fn new() -> Self;
    /// 输入一条 SSE 消息的 data JSON 文本，产出零或一个 StreamEvent
    pub fn feed(&mut self, data: &str) -> wavecode_llm::Result<Option<StreamEvent>>;
}
```

**5 个内置工具**（schema 手写 JSON，不引 schemars）：

| name | 只读 | 参数 | 行为要点 |
|---|---|---|---|
| `read_file` | 是 | `path`（必填）, `offset`, `limit` | 默认从头读，上限 2000 行 / 50KB，超限截断并标注；UTF-8 校验 |
| `write_file` | 否 | `path`, `content`（均必填） | 自动创建父目录；整文件覆盖 |
| `edit_file` | 否 | `path`, `old_string`, `new_string`（均必填） | `old_string` 须唯一匹配，0 或 >1 次匹配报错 |
| `list_dir` | 是 | `path` | 排序输出，目录加 `/` 后缀，上限 1000 条 |
| `shell` | 否 | `command`（必填）, `timeout_ms`（默认 60000，上限 300000） | Windows `cmd /C`、Unix `sh -c`（env `WAVECODE_SHELL` 可覆盖）；捕获 stdout+stderr，各截断 30KB |

**路径安全（M1 简化安全边界）:** 所有 fs 工具把 `path` 解析到 `ctx.cwd` 下，canonicalize 后必须仍以 cwd 为前缀，否则返回错误（防逃逸）。shell 以 `ctx.cwd` 为工作目录执行。

### core crate — Session（`crates/core/src/lib.rs` + `session.rs`）

```rust
pub struct Session {
    // config 快照、model: Arc<dyn ChatModel>、registry: Registry、
    // messages: Vec<Message>（会话历史）、interrupted: Arc<AtomicBool>
}
impl Session {
    pub fn new(cfg: SessionConfig) -> Self;
    /// 执行一个 turn：流式采样 → 工具编排 → 循环直至 end_turn；
    /// 全程经 events 发送 protocol::Event；返回最终 stop_reason
    pub async fn run_turn(
        &mut self,
        submission_id: &str,
        text: &str,
        events: tokio::sync::mpsc::Sender<wavecode_protocol::Event>,
    ) -> anyhow::Result<wavecode_protocol::StopReason>;
}

pub struct SessionConfig {
    pub model_name: String,
    pub context_window: u64,
    pub max_output_tokens: u32,
    pub model: std::sync::Arc<dyn wavecode_llm::ChatModel>,
    pub registry: wavecode_tools::Registry,
    pub cwd: std::path::PathBuf,
}
```

turn 循环（对齐 SPEC §5.1，M1 无 hooks/审批/压缩）：

1. push `Message{User, [Text]}` → emit `TurnStarted{turn_id: uuid}`。
2. 组装 `ChatRequest`（system 为内置编码代理提示词，见 Task 7）→ `model.stream`。
3. 边流边 emit `AgentMessageDelta`；tool_use 块累计 partial_json，块结束 parse 为完整 input。
4. 采样结束：若有 tool_use → 对每个调用 emit `ToolCallBegin` → 执行（同批内 read_only 的用 `futures::future::join_all` 并行，非只读串行，保持声明序）→ emit `ToolCallEnd` → 全部结果作为一个 user 消息的 `ToolResult` 块 push → 回 2。
5. `stop_reason == "end_turn"` → emit `AgentMessageComplete` + `TokenCount` + `TurnCompleted{Completed}`；`max_tokens` → emit `Warning` 后按 Completed 处理（M1 不自动续写）。
6. Interrupt（`interrupted` flag 置位）→ 安全点停止，emit `TurnCompleted{Interrupted}`。

系统提示词（内置常量，中文注释说明分层意图）：

```text
You are WaveCode, an AI coding agent operating in a CLI.
Working directory: {cwd}
Rules:
- Use tools to act on the filesystem; prefer edit_file for modifying existing files.
- Keep answers concise; after finishing tool work, summarize what you did.
- Never fabricate file contents or command results.
```

### cli crate — 命令面（`crates/cli/src/main.rs`）

```text
wavecode                      # 基础交互 REPL（rustyline，流式渲染）
wavecode exec "<prompt>"      # 非交互单 turn；--json 输出 JSONL（每行一个 Event）
wavecode --model <name>       # 覆盖 config.model
```

REPL 交互：`/quit`、`/exit` 退出；其余输入作为 UserInput；渲染规则——`AgentMessageDelta` 直接追加打印；`ToolCallBegin` 打印 `▸ tool {name} {input 摘要≤80字符}`（暗淡色）；`ToolCallEnd` 失败时打印错误摘要；`TokenCount` 在每轮结束打印 `tokens: used/window`；`Warning/Error` 原样打印。exec 默认渲染同 REPL（加换行收尾），`--json` 时每事件一行 `serde_json::to_string(&Event)` 到 stdout，人类可读渲染转 stderr。

`main.rs` 的 clap 结构：

```rust
#[derive(clap::Parser)]
#[command(name = "wavecode", version, about = "WaveCode — AI coding agent")]
struct Cli {
    /// 覆盖 config.model
    #[arg(long, global = true)]
    model: Option<String>,
    /// 配置文件路径（默认 ~/.wavecode/config.toml）
    #[arg(long, global = true)]
    config: Option<std::path::PathBuf>,
    #[command(subcommand)]
    command: Option<Command>,
}

#[derive(clap::Subcommand)]
enum Command {
    /// 非交互执行单个 prompt
    Exec {
        prompt: String,
        /// 以 JSONL 输出事件流（人类渲染转 stderr）
        #[arg(long)]
        json: bool,
    },
}
```

`bootstrap.rs`：`Config::load`（或 `--config` 指定）→ `resolve_provider` → `AnthropicClient::new` → `SessionConfig`（`Registry::builtin()`、cwd = 当前目录、`--model` 覆盖）。无子命令 → REPL：rustyline `DefaultEditor` 循环读行，`/quit|/exit` 退出、空行跳过，其余 `submit(UserInput)` 后轮询 `next_event` 渲染直到 `TurnCompleted`。exec：submit 后同样消费到 `TurnCompleted`，以 stop_reason 决定退出码（Completed=0，其他=1）。

渲染（契约 cli 一节的规则）：human 模式 delta 直接 `print!` 不换行 flush；ToolCallBegin 打印 `\n▸ {tool} {input≤80字符}\n`；ToolCallEnd 且 !ok 打印 `✗ {output≤200字符}`；TurnCompleted 前换行并打印 `tokens: {used}/{window}`（取最近一次 TokenCount）；`--json` 时每事件一行 JSON。

错误路径：config 缺失时打印中文指引（如何创建 `~/.wavecode/config.toml`，含模板，**模板中 api_key 行注释说明**）并以退出码 2 退出。
